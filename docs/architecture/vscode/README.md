# VS Code

The primary VS Code workspace is defined by the root [.devcontainer/devcontainer.json](../../../.devcontainer/devcontainer.json). It provides the shared workspace for repository scripts and Compose-managed application services; use the app containers as the runtime and test environments.

Repository conventions are documented in [AGENTS.md](../../../AGENTS.md). Tool adapters and path-specific Copilot instructions live under [.github](../../../.github/), while backend, frontend, and infrastructure `AGENTS.md` files hold their component-specific commands and practices. The root [README](../../../README.md#start-developing) describes starting the local workspace and application stack.
